# هم‌صحبت — گفت‌وگوی آنلاین

برنامه وب فارسی برای ثبت‌نام، ورود، گفت‌وگوی عمومی، ارسال عکس و اشتراک‌گذاری زنده عدد با همه کاربران واردشده. داده‌ها در Supabase ذخیره می‌شوند.

## راه‌اندازی Supabase

1. یک پروژه رایگان در Supabase بساز.
2. از Project Settings سپس API، آدرس پروژه و کلید عمومی anon یا publishable را بردار. از کلید service_role یا secret استفاده نکن.
3. از SQL Editor، فایل supabase-schema.sql همین مخزن را باز کن و تمام کد آن را اجرا کن.
4. از Authentication > Providers > Email، ورود با ایمیل را فعال نگه دار. برای تست سریع می‌توانی تأیید ایمیل را خاموش کنی؛ برای استفاده واقعی بهتر است روشن باشد.
5. از Database > Publications، جدول messages را به publication با نام supabase_realtime اضافه کن تا پیام‌ها و عددها زنده به کاربران برسند.
6. برنامه را باز کن، آدرس پروژه و کلید عمومی را وارد کن و ثبت‌نام کن.

## انتشار وب

در مخزن GitHub به Settings > Pages برو و در بخش Build and deployment گزینه Source را روی GitHub Actions قرار بده. سپس هر push به شاخه main سایت را به‌روزرسانی می‌کند و نشانی آن خواهد بود:

https://matin7-crypto.github.io/ff/

## ساخت APK اندروید

فایل‌های پروژه اندروید در پوشه android قرار دارند. با هر push به main، GitHub Actions به‌صورت خودکار APK آزمایشی را می‌سازد.

برای دریافت APK:
1. وارد زبانه Actions مخزن شو.
2. اجرای موفق با نام Build Android APK را باز کن.
3. در بخش Artifacts فایل hamsobat-debug-apk را دانلود کن.
4. فایل ZIP را باز کن و app-debug.apk را روی گوشی نصب کن.

APK یک پوسته اندرویدی برای نسخه آنلاین وب است؛ برای کارکردن باید اینترنت و انتشار GitHub Pages فعال باشد.

## امنیت

- فقط کاربران واردشده می‌توانند پیام‌ها و عددها را بخوانند یا ارسال کنند.
- هر کاربر فقط می‌تواند پیام را با شناسه خودش ثبت کند.
- کلید عمومی Supabase برای استفاده در مرورگر طراحی شده است؛ کلیدهای secret و service_role را هرگز در فایل‌های سمت کاربر قرار نده.
- این نسخه اتاق عمومی دارد؛ پیام خصوصی، گروه‌ها، گزارش/مسدودسازی و مدیریت محتوا هنوز پیاده‌سازی نشده‌اند.
