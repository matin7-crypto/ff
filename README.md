# هم‌صحبت — گفت‌وگوی آنلاین

برنامه وب فارسی برای ثبت‌نام، ورود، گفت‌وگوی عمومی و ارسال عکس. اطلاعات کاربران، پیام‌ها و عکس‌ها در پروژه Supabase ذخیره می‌شود.

## راه‌اندازی سرور

1. در سایت Supabase یک پروژه رایگان بساز.
2. از Project Settings سپس API، آدرس پروژه و کلید عمومی anon یا publishable را بردار. از کلید service_role یا secret استفاده نکن.
3. از SQL Editor، فایل supabase-schema.sql همین مخزن را باز کن و تمام کد آن را اجرا کن.
4. از Authentication سپس Providers سپس Email، ورود با ایمیل را فعال نگه دار. برای تست سریع می‌توانی تأیید ایمیل را خاموش کنی؛ برای استفاده واقعی بهتر است تأیید ایمیل روشن باشد.
5. از Database سپس Publications، جدول messages را به publication با نام supabase_realtime اضافه کن تا پیام‌ها زنده به کاربران برسند. اگر از قبل اضافه است دوباره اضافه نکن.

## اجرای برنامه

- فایل‌های index.html، style.css و app.js را روی یک هاست استاتیک منتشر کن؛ GitHub Pages هم قابل استفاده است.
- در اولین بازکردن، آدرس پروژه و کلید عمومی Supabase را داخل صفحه وارد کن.
- ثبت‌نام کن و وارد اتاق گفت‌وگو شو.

## نکات امنیتی

- فقط کاربران واردشده می‌توانند پیام‌ها را بخوانند یا ارسال کنند.
- هر کاربر فقط می‌تواند با شناسه خودش پیام ثبت کند.
- کلید عمومی Supabase برای استفاده در مرورگر طراحی شده است؛ کلیدهای secret و service_role را هرگز در فایل‌های سمت کاربر قرار نده.
- این نسخه اتاق عمومی دارد؛ پیام خصوصی، گروه‌ها، گزارش/مسدودسازی و مدیریت محتوا هنوز پیاده‌سازی نشده‌اند.
