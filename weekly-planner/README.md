# برنامه هفتگی

سورس پروژه اصلی داخل فایل `source.zip` قرار دارد. گردش‌کار GitHub Actions در ریشه مخزن، این آرشیو را استخراج و APK اندروید را می‌سازد.

برای دریافت APK:
1. وارد زبانه Actions مخزن شوید.
2. اجرای **Build Weekly Planner APK** را باز کنید.
3. پس از موفقیت، از بخش Artifacts فایل **weekly-planner-apk** را دریافت کنید.
