# برنامه هفتگی (Flutter)

سورس برنامه با Flutter و Dart در فایل فشرده‌ی Base64 به نام `source.zip.b64` نگهداری می‌شود. گردش‌کار GitHub Actions آن را استخراج می‌کند، پوشه‌ی Android را می‌سازد و APK را تولید می‌کند.

برای دریافت APK:
1. وارد زبانه‌ی Actions مخزن شوید.
2. اجرای **Build Weekly Planner APK** را باز کنید.
3. پس از موفقیت، از بخش Artifacts فایل **weekly-planner-apk** را دانلود کنید.
